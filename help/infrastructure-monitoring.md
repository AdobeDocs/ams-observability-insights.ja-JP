# ホストインフラストラクチャ監視ダッシュボード

このセクションでは、インフラストラクチャ監視ダッシュボードに表示される各ホストレベルのインフラストラクチャ監視グラフについて説明します。 各セクションでは、指標の目的、収集されるデータ、測定単位、ビジュアライゼーションに表示される情報について説明します。

## ダッシュボードの概要

ホストインフラストラクチャ監視ダッシュボードは、基盤となるホストの稼働率とパフォーマンスをリアルタイムで可視化します。 これらの指標は、オペレーターがコンピューティング、メモリ、ストレージ、ネットワークリソースを監視し、潜在的なリソースのボトルネックを特定するのに役立ちます。

ダッシュボードには、次の監視パネルが含まれています。

- ホスト CPU稼働率
- ホストディスク I/O
- ホストネットワーク I/O
- CPU I/O Wait
- ストレージ使用状況
- ディスク使用量
- ホストCPUの読み込み平均
- ホストメモリ使用率

## &#x200B;1. ホスト CPU稼働率

![ ホスト CPU利用状況](assets/host-monitoring/host_cpu_utilization.png)

### 説明

**ホスト CPU利用状況** パネルには、現在オペレーティングシステムおよび実行中のすべてのプロセスが時間の経過に伴って使用しているCPU リソースの割合が表示されます。

この指標は、ホスト全体でのCPUの使用状況を表し、プロセッサのアクティビティを時系列で視覚化します。

このグラフにより、オペレーターは、選択した観察ウィンドウ中にCPUの消費量がどのように変化するかをモニタリングできます。

### 指標

| 指標 | 説明 |
| --------- | ---------------------------------------- |
| `cpu_pct` | 現在使用されているCPUの割合 |

### 購入点数

- 割合（%）

### 表示される統計

このパネルでは、次の3つの値を使用してCPUの使用状況を要約します。

| 統計 | 説明 |
| --------- | --------------------------------------------------------------- |
| 平均 | 選択した期間の平均CPU使用率 |
| 最終 | 最近収集されたCPU利用率 |
| Max | 選択した時間範囲で最も高いCPU使用率が観察されました |

### グラフコンポーネント

- CPUの使用率を表す時系列行。
- パーセント ベースのY軸の範囲は&#x200B;**0%から100%です**。
- グラフの下に表示される概要統計。
- 選択したモニタリング間隔の過去の傾向。

## &#x200B;2. ホストディスク I/O

![ ホスト ディスク I/O](assets/host-monitoring/host_disk_io.png)

### 説明

**Host Disk I/O** パネルには、ホストが実行したディスク読み取りおよびディスク書き込み操作のストレージ スループットが表示されます。

グラフには、オペレーティングシステムとストレージデバイス間で転送されるデータを表す2つの独立した時系列が表示されます。

このビジュアライゼーションは、ストレージのアクティビティを経時的に監視するのに役立ち、insightにディスクからの読み取りと書き込みのデータ量を提供します。

### 指標

| 指標 | 説明 |
| ------------ | --------------------------------- |
| `disk_read` | ストレージから読み取られたデータの量 |
| `disk_write` | ストレージに書き込まれるデータ量 |

内部的には、これらの指標は、スループットがスムージングされた値を使用して表示されます。

### 購入点数

- バイト/秒（B/s）
- 1秒あたりのキロバイト数（KB/秒）
- 1秒あたりのメガバイト数（MB/秒）
- 1秒あたりのギガバイト数（GB/秒）

表示される単位は、スループットに基づいて自動的にスケーリングされます。

### グラフコンポーネント

- ディスク読み取りスループットを表す緑の線。
- ディスクの書き込みスループットを表すオレンジ色の線。
- 時系列の可視化：
- 各指標に対して個別の凡例を使用します。
- 各系列の横に表示される現在の指標値。

## &#x200B;3. ホストネットワーク I/O

![ ホスト ネットワーク I/O](assets/host-monitoring/host_network_io.png)

### 説明

**Host Network I/O** パネルには、ホストが時間をかけて送信および受信したネットワーク トラフィックの量が表示されます。

このグラフは、ネットワークインターフェイスを流れるデータの速度を測定し、ネットワーク帯域幅の消費量を可視化します。
この指標は、ネットワークのスループットを表します。

### 指標

| 指標 | 説明 |
| --------------- | --------------------------------------------------------------------- |
| `bytes_per_sec` | 1秒あたりの転送バイト数として測定されるネットワーク スループットの集約 |

### 購入点数

グラフは自動的に次の間にスケールします。

- バイト/秒
- KB/秒
- MB/秒
- GB/秒

トラフィック量に応じて異なります。

### 表示される統計

| 統計 | 説明 |
| --------- | ---------------------------------- |
| 平均 | 平均ネットワークスループット |
| 最終 | 最新のスループット測定 |
| Max | 最高スループットを達成 |

### グラフコンポーネント

- 単一のスループットライン：
- 時系列の可視化：
- 動的な帯域幅の拡張：
- チャートの下に表示される概要統計。

## 4. CPU I/O Wait

![CPU I/O Wait](assets/host-monitoring/cpu_io_wait.png)

### 説明

**CPU I/O Wait** パネルには、入出力操作の完了を待つためにCPUが費やした時間の割合が表示されます。

このメトリックは、アクティブなプロセスがストレージ・デバイスまたはその他のI/O操作を待機中にブロックされることで発生するプロセッサのアイドル時間を表します。

このグラフは、I/O待機時間の変化を視覚化しています。

### 指標

| 指標 | 説明 |
| --------- | ------------------------------------------------------ |
| `cpu_pct` | I/O処理の待機時間に対するCPUの割合 |

### 購入点数

- 割合（%）

### 表示される統計

| 統計 | 説明 |
| --------- | ------------------------------- |
| 平均 | CPU I/Oの平均待機率 |
| 最終 | 直近に記録された価値 |
| Max | 最高の記録値 |

### グラフコンポーネント

- 時系列線：
- パーセント単位のY軸
- 概要統計。
- 過去のトレンドを可視化：

## &#x200B;5. ストレージ使用状況

### 説明

**ストレージ使用率** パネルには、監視対象ホストで現在使用されているストレージ容量の全体的な割合が表示されます。

### 指標

| --------------- | -------------------------------------------------- |
| ストレージ使用率% | 現在消費されている割り当て済みストレージの割合 |

### 購入点数

- 割合（%）

### グラフコンポーネント

- 時系列利用率グラフ。
- パーセンテーションスケール：
- 過去のストレージ使用率のトレンド：

## &#x200B;6. ディスク使用量

![ ディスク使用量](assets/host-monitoring/storage_disk_usage.png)

### 説明

「**ディスク使用状況**」パネルには、マウントされた各ファイルシステムまたはストレージデバイスのストレージ使用率が表示されます。

各行は、特定のブロックデバイスまたはマウントされたパーティションに対応し、現在使用されているスペースの割合をレポートします。

この表は、ストレージ使用率のファイル・システム・レベルの内訳を示しています。

### 表示される情報

各エントリには次のものが含まれます。

| フィールド | 説明 |
| --------------- | -------------------------------------------- |
| デバイス | マウントされたストレージ・デバイスまたはファイル・システム |
| 使用済% | 使用済みストレージ容量の割合 |
| 利用状況バー | ストレージ消費の視覚的な表現 |

### 購入点数

- 割合（%）

### グラフコンポーネント

- ファイルシステム/デバイスリスト：
- 稼働率：
- 色分けされたキャパシティインジケーター。
- ソートされた稼働率の値。

## &#x200B;7. ホストCPUの読み込み平均

![ ホスト CPUの読み込み平均](assets/host-monitoring/host_cpu_load_average.png)

### 説明

**Host CPU Load Average** パネルには、3つのローリング時間ウィンドウにわたるLinux システムのロード平均が表示されます。

CPUの使用率とは異なり、負荷平均は、アクティブに実行されているか、CPUのスケジュールまたはI/Oの完了を待っているプロセスの平均数を表します。

このグラフには、短期的および長期的な作業負荷の傾向を示す3つのローリング平均が同時に表示されます。

### 指標

| 指標 | 説明 |
| ---------- | -------------------------------------------- |
| `load_1m` | 過去1分間の平均システム負荷 |
| `load_5m` | 過去5分間の平均システム負荷 |
| `load_15m` | 過去15分間の平均システム負荷 |

### 購入点数

- 負荷平均（次元なし値）

### 表示される統計

各負荷平均指標について：

| 統計 | 説明 |
| --------- | --------------------------------------- |
| 平均 | 選択した時間範囲の平均負荷 |
| 最終 | 最新の記録済み負荷値 |
| Max | 最も高い負荷値 |

### グラフコンポーネント

- 3つの独立したトレンドライン。
- 時系列の可視化：
- 各回転平均の個々の凡例。
- 各指標の概要統計。

## &#x200B;8. ホストメモリ使用率

![ ホスト メモリ使用率](assets/host-monitoring/host_memory_usage.png)

「**ホストメモリ使用率**」パネルには、オペレーティングシステムによって現在割り当てられている物理システムメモリの割合が表示されます。

この指標は、実行中のすべてのプロセス、カーネルメモリ、バッファ、およびキャッシュにおける全体的なRAM使用率を表します。

このグラフは、選択した監視期間中のメモリ消費量を連続して表示します。

### 指標

| 指標 | 説明 |
| ------------ | ---------------------------------------------- |
| `memory_pct` | 現在使用されている物理メモリの割合 |

### 購入点数

- 割合（%）

### 表示される統計

| 統計 | 説明 |
| --------- | ---------------------------------- |
| 平均 | 平均メモリ使用率 |
| 最終 | 直近に記録された稼働率 |
| Max | 最高の利用率を達成 |

### グラフコンポーネント

- 時系列メモリ使用率グラフ。
- パーセント単位のY軸
- 過去の利用状況の傾向：
- 概要統計。

| ダッシュボードパネル | プライマリ指標 | 単位 |
